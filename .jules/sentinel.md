## 2024-05-24 - Dynamic Verification Tokens\n**Vulnerability:** Hardcoded verification tokens in `server.ts` routes (`sign-agreement` and `sign-deed`).\n**Learning:** Hardcoded verification tokens allow predictability and bypassing of verification flows. Generating tokens dynamically per request is critical.\n**Prevention:** Use cryptographically secure methods (e.g., `crypto.randomBytes`) instead of hardcoded strings for token generation.
