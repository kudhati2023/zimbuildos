## 2024-10-23 - Focus Rings and Aria-Labels for Icon/Dismiss Buttons
**Learning:** In this application, many critical global actions (like Refresh, Sign In/Out) and alert dismiss buttons ('×') lack screen reader accessibility (`aria-label`) and visual keyboard focus indicators. The current UX standard requires intent-colored focus rings.
**Action:** When working on icon-only buttons or simple text dismiss buttons, always add `aria-label` to provide context for screen readers. Furthermore, implement keyboard accessibility using Tailwind classes `focus-visible:outline-none focus-visible:ring-2 rounded-md`, and match the ring color to the action's intent (e.g., `focus-visible:ring-indigo-500` for default actions, `focus-visible:ring-rose-500` for destructive/dismiss actions, `focus-visible:ring-emerald-500` for success).
